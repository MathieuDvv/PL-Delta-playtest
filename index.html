Delta

A fan-made Pokémon adventure around Sky Pillar Port and the Verdance Isles. This build is for friends, mostly to test online battles.

Download for Windows 64-bit Windows · about 2 GB · all builds

Install

  1. Unzip the whole folder anywhere, then run Delta.exe. Keep Delta.pck next to it.
  2. If Windows SmartScreen warns about an unknown app, click More info, then Run anyway. The build isn't signed.
  3. When Windows Firewall asks whether Delta can use the network, click Allow (private networks at least). Online battles need it.

Battle a friend online

  1. Both players walk into the Pokémon Center and talk to the Online Battle Attendant.
  2. One player chooses Host a battle. The game opens a port on their router by itself and shows an Internet link code, such as 2RNK3-W6YQY.
  3. The host sends that code (Discord, text…). The other player chooses Join a battle and types it.
  4. Draft three Pokémon each from the grid, press Battle!, and fight. Nothing is lost: it uses full-health copies.

On the same Wi-Fi, use the Same network code, or pick the host from the list. If the host's screen says the router refused or no router answered, someone else should try hosting, or forward UDP port 47870 to the host's PC. Some internet providers share one address between homes; then only the other player can host.
